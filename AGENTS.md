# Codex instructions - SmallSide

When adapting the program from `data/reflections/inbox/`:

1. Read the product brief, decisions, adaptation log, current session, and next two sessions.
2. Summarize evidence across reflections; distinguish one-off observations from recurring patterns.
3. Protect safety, joy, belonging, equal opportunity, rotation, ball contacts, realistic small-sided play, and no elimination.
4. Propose changes before editing when they alter the season theme. Small activity adaptations may be implemented with an explanation.
5. Do not create rankings or infer ability, diagnosis, personality, or potential. Do not retain identifying or medical data.
6. Prefer revisiting a successful activity with one changed variable.
7. Log approved changes in `docs/development/ADAPTATION_LOG.md`, including evidence and review date.
8. Never edit Google Calendar unless explicitly asked. Calendar sync is read-only and creates sanitized `data/schedule.json`.
9. Preserve Cloudflare Pages portability: core features must remain static and browser-native; isolate nginx, Python and filesystem writes as optional deployment adapters.
